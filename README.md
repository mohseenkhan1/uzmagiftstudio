# Uzma Gifts

Gift-shop content update for the existing Uzma Journal layout. Sidebar navigation, colors, layout, typography, social media links, filters, saved items and responsive behavior are preserved. Only the copy and image subjects were changed to gifting: hampers, bouquets, Nikah Nama, mobile covers and personalised gifts.

## Run locally
```bash
npm install
npm run dev
```

No MongoDB or backend is used. Images are remote Unsplash URLs and require internet access. The email signup is a front-end demo only.
